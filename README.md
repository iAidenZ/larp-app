# Game Activity

Shows a game as your Discord activity. Windows only.

## Setup
1. Install Python 3.8 or newer (tick "Add Python to PATH").
2. Double-click `run.bat`.
3. In Settings, put your App ID (Discord Developer Portal > your app > Application ID).

## Modes
- Run .exe: starts the stand-in program.
- Status only: uses the game's own ID.
- Rich Presence: uses your own App ID.

## Vencord streaming plugin (optional)
Copy `vencord-plugin/OneClickStream` into Vencord's `src/userplugins/` and rebuild.
Needs the PhilsPluginLibrary plugin.
